# 1. Core Computer and Network Concepts

[[00 - Overview|← Overview]]

**Related Security+ material:** [[1.1 - Security Controls]]

| Term | Simple Explanation | Example | Security+ Why It Matters |
|---|---|---|---|
| **Computer** | A machine that processes instructions, stores data, and communicates with other devices. | Desktop, laptop, or server. | Attackers target computers, their data, and the software running on them. |
| [[2.3 - Hardware Vulnerabilities\|Hardware]] | The physical parts of a computer. | CPU, memory, hard drive, and network card. | Hardware failures and malicious devices can create security risks. |
| **Software** | Instructions that tell hardware what to do. | Windows, Chrome, or Microsoft Word. | Vulnerable or malicious software causes many security incidents. |
| [[2.3 - Operating System Vulnerabilities\|Operating system]] | The main software that manages a computer’s hardware, files, users, and applications. | Windows 11, Linux, or macOS. | Security teams must patch and harden operating systems. |
| [[2.4 - Application Attacks\|Application]] | Software designed to perform a particular task. | A browser, email client, or payroll program. | Applications can contain vulnerabilities or process malicious input. |
| **Process** | A currently running instance of a program. | Opening Chrome starts one or more Chrome processes. | Malware runs as processes and may imitate legitimate ones. |
| [[2.4 - Denial of Service\|Service]] | A program that runs in the background and provides a function. | A web service listens for website requests. | Unnecessary or vulnerable services increase the attack surface. |
| [[3.2 - Network Appliances\|Network]] | A group of devices connected so they can exchange information. | Your laptop, phone, and printer on home Wi-Fi. | Security+ focuses heavily on protecting network communication. |
| **Internet** | A worldwide collection of smaller networks connected together. | Your home network connects to Google through your ISP. | Most organizations connect internal systems to the Internet. |
| **Intranet** | A private network or website used inside an organization. | An employee-only HR portal. | Internal systems still require access controls and monitoring. |
| **Extranet** | A private network that gives limited access to outside partners. | A supplier accesses a company ordering portal. | Organizations must restrict what outside users can reach. |
| **Node** | Any device connected to a network. | Laptop, router, printer, or camera. | Security tools track and protect network nodes. |
| **Host** | A network device with an IP address that sends or receives traffic. | A desktop computer at 192.168.1.20. | Hosts serve as sources and destinations for attacks. |
| [[4.5 - Endpoint Security\|Endpoint]] | A user-facing device at the edge of a network. | Laptop, phone, or tablet. | Endpoint security protects common entry points for attackers. |
| **Client** | A device or program that requests a service from another system. | Your browser requests a webpage. | Clients often initiate connections and process untrusted content. |
| **Server** | A computer or program that provides services to clients. | A web server sends webpages to browsers. | Servers commonly store sensitive data and face constant attacks. |
| **Peer-to-peer** | Devices communicate directly without relying on one central server. | Two computers share files directly. | Peer-to-peer traffic can bypass centralized controls. |
| **Local** | Located on the device or nearby network you currently use. | A file saved on your laptop. | Local access differs from remote network access. |
| **Remote** | Located on another system and reached through a network. | Logging into a server from home. | Remote access requires strong authentication and encryption. |
| **On-premises** | Technology physically hosted and managed at an organization’s location. | A server rack in a company building. | The organization controls the equipment and its security. |
| **Data** | Information stored or processed by a system. | Documents, passwords, customer records, or images. | Security protects data from disclosure, alteration, and destruction. |
| **Data at rest** | Data stored somewhere and not currently moving. | Files on a hard drive. | Encryption protects stolen drives and storage systems. |
| **Data in transit** | Data moving between systems. | An email traveling across the Internet. | TLS, VPNs, and other protections prevent interception. |
| **Data in use** | Data currently being processed by a computer. | A decrypted document open in memory. | Attackers may target memory or active sessions. |
